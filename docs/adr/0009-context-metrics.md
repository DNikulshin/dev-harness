# 0009. Контекст — измеряемая величина: размер в байтах, стоимость в токенах

- **Статус:** принято
- **Дата:** 2026-11-21
- **Контекст:** spike #105. Внешний ориентир (гайд «AI-инженерия с нуля») утверждает, что узкое
  место цикла переехало из генерации кода в **контекст и проверку**. В нашем нормативе эти понятия
  закрыты процедурно (`context engineering`, `observability`), но не измеримо. Проверенные по коду
  факты:

  1. `metrics.json` уже пишет расход: `tokens` по стадиям
     `{runs, input, cache_read, cache_write, output, reasoning}` и `cost_rub`
     (`scripts/cycle-metrics.mjs`), плюс `applied_limits` с источником каждого лимита. Доля кэша не
     считается, и эти числа ни с чем не сводятся: вопросам «сколько контекста стоит итерация» и
     «растёт ли он» они не отвечают.
  2. Разреза по итерациям в `usage.json` **нет**: файл хранит суммы по этапам, которые дописываются
     и не затираются (`scripts/cycle-usage.mjs`, `USAGE_STAGES`; `runs` — число вызовов этапа).
     Восстановить «сколько токенов ушло на итерацию n» задним числом не из чего.
  3. `evidence/` собирается с фиксированными именами (`EVIDENCE_FILES`,
     `scripts/cycle-evidence.mjs:139`) и **перезаписывается** на каждой сборке
     (`writeEvidenceFiles`, `scripts/cycle-evidence.mjs:795`): `issue.md`, `criteria.md`,
     `diff.patch`, `gates.json`, `integrity.json`, `qa-web.json`, логи в `gates/`. `packet` считает
     байты и строки диффа и печатает их в stdout вместе со списком файлов (`runPacket`,
     `scripts/cycle-evidence.mjs:931`), но ни в один файл они не попадают: история размеров не
     сохраняется вообще.
  4. Лимиты `evidenceTailLines`, `maxDiffBytes`, `logMaxBytes`
     (`scripts/lib/cycle/limits.mjs:38-41`) — фактический бюджет контекста. Нарушение видно только
     как код 4 на записи (`diff_too_large`), измерения в артефактах нет: порог нельзя откалибровать
     по данным, только на глаз.
  5. `cycle-report` (markdown и `--html`) сводит факты по циклам, колонок контекста в нём нет; §11
     `docs/orchestrator.md` требует «только факты, без сравнения с порогами».
  6. В `.pi/artifacts/` этого репозитория боевых циклов нет — наблюдённой базы для порога нет ни
     одной.

## Решение

**(а) Две единицы, каждая на своём вопросе.** Размер контекста меряется **байтами и строками**
файлов `evidence/`: это свойство файлов, а не модели — провайдер-независимо, воспроизводимо,
читается с диска. Стоимость меряется **токенами** из `usage.json`; доля кэша считается как
`cache_read / input` и равна `null` при нулевом `input` (а не нулю: «кэша не было» и «замера нет» —
разные факты).

**(б) Снимок при сборке, агрегат постфактум.** `cycle-evidence packet` пишет снимок вместе с пакетом
— в памяти и только при успехе, как и сам пакет, — в `manifest.<n>.json` каталога цикла:
`iteration`, `base_sha`, `files[]` (`{path, bytes, lines}`, порядок — сортировка по пути) и
`totals {files, bytes, lines}`. `cycle-metrics` читает снимки и кладёт в `metrics.json` блок
`context`.

Две причины, почему именно так:

- **не только постфактум:** `evidence/` перезаписывается, поэтому после цикла восстанавливается
  только последняя итерация; снимок при сборке — единственная точка, где измерение вообще
  существует;
- **не в `evidence/`:** замороженный пакет — вход оценщика, телеметрии в нём не место. Тот же
  аргумент, по которому `driver.jsonl` (#47) лежит в каталоге цикла, а не в пакете.

**(в) Рост — по итерациям, стоимость — по стадиям.** `evidence_growth` — отношение размера пакета к
предыдущей итерации по байтам и по файлам, у первой итерации `null`. Разрез токенов по итерациям не
вводится: в `usage.json` его нет (факт 2), а делить сумму на число итераций значит выдавать
производное число за замер. Доля кэша считается по стадии и по циклу — столько, сколько есть в
фактах.

**(г) Сначала наблюдение, не гейт.** Решение не вводит ключей `limits` и правил в `cycle-decide`.
Порог `contextGrowthRatio` — отдельная задача по 3–5 наблюдённым циклам, тем же порядком, каким
выставлялся `maxCycleCostRub` (§11). Порог без базы или мёртвый (никогда не срабатывает), или
ломающий (первая же нормальная итерация уходит в эскалацию).

**(д) Отчёт показывает, но не судит.** `cycle-report` (markdown и `--html`) получает колонки: размер
пакета, рост по итерациям, расход и доля кэша. Правило §11 «только факты» распространяется на новые
колонки: сравнение с порогами и оценки «хорошо/плохо» в отчёт не попадают.

**(е) Секреты не печатаем — теперь буквально.** В манифесте только пути, байты и строки. Маскировать
нечего, потому что содержимого там нет; это проверяется тестом, а не обещанием.

**(ж) Чего решение не даёт.** Гранулярность снимка — файл пакета, а не раздел промпта: вопрос «какой
именно фрагмент контекста дорог» остаётся без ответа. Разрез по итерациям в токенах тоже
отсутствует. Если байтовой картины не хватит, это отдельное решение со своими фактами, а не тихое
расширение этого.

## Последствия

- **Положительные:** на вопрос «деградирует ли цикл по контексту» появляется ответ из артефакта, а
  не из ощущения; калибровка `evidenceTailLines` и `maxDiffBytes` становится возможной по данным;
  измерение почти бесплатно — числа уже считаются в памяти `packet` и уже печатаются в stdout;
  стоимость не дублируется: токены остаются там, где они есть, и к ним добавляется одна производная
  величина (`cache_share`).
- **Отрицательные / цена:** контракт артефактов расширяется (`manifest.<n>.json` в Приложении A плюс
  валидатор) — это второй писатель измеримых величин после `metrics.json`, и формат манифеста
  придётся держать согласованным с `cycle-metrics`; история появляется только с момента реализации,
  прошлые циклы задним числом не измеряются; байты — прокси контекста, а не сам контекст (один и тот
  же дифф в разных моделях стоит по-разному).
- **Что становится запрещено:** писать в манифест содержимое файлов, выдержки и хэши содержимого;
  класть телеметрию замера в `evidence/`; выводить порог и правило `cycle-decide` до наблюдённой
  базы; показывать в отчёте оценки вместо фактов; объявлять «ростом» размер последней итерации,
  когда предыдущих нет.

| Только байты                                              | провайдер-независимо                                        | теряется фактическая стоимость цикла, которая уже посчитана и уже лежит в `metrics.json`                                           |

| Снимок в `evidence/manifest.json`                         | рядом с тем, что измеряем                                   | телеметрия попадает в замороженный вход оценщика; файл внутри перезаписываемого каталога требует собственной append-only семантики |

## Проверка

- Тест `cycle-evidence`: два прогона `packet` на одном дереве дают побайтно одинаковый
  `manifest.<n>.json`; при ошибке сборки файла нет.
- Тест «секретов не печатаем»: ни одна строка из `diff.patch` и логов гейтов не встречается в
  `manifest.<n>.json` и в блоке `context`; в манифесте нет ничего, кроме `path`, `bytes`, `lines`.
- Тест `cycle-metrics`: фикстура двух итераций даёт `evidence_growth > 1`, фикстура без роста —
  `= 1`; отсутствие манифеста даёт `null` и перечень отсутствующих файлов, а не нули; `cache_share`
  равен `null` при нулевом `input`.
- Тест `cycle-report`: новые колонки есть в markdown и в `--html`; страница остаётся без `<script>`,
  без внешних `src`/`href` и побайтно детерминированной.
- Ревью-правило: новых ключей в `LIMIT_RULES` и новых правил в `cycle-decide` этот PR не добавляет;
  проверяется диффом, а не памятью.
