# Норматив протокола

Точка входа в нормативные документы цикла.

- [orchestrator-core.md](./orchestrator-core.md) — реализация ядра: форматы артефактов (Приложения
  A–D), протокол супервизора, задачи T*.
- [orchestrator.md](./orchestrator.md) — политика и требования к поведению.

При противоречии в политике действует `orchestrator.md`, в деталях реализации —
`orchestrator-core.md`.

Проектные значения (гейты, лимиты, пути, провайдер) подставляются из `.pi/harness.config.json`
проекта. Ядро не содержит гейтов конкретного проекта: пустой список гейтов — валидное состояние,
`cycle-gates` сообщает «гейты не заданы» с кодом 2.

## Происхождение

Документы пришли из проекта-источника без правки содержания и помечены шапкой. Журнал переноса (что
откуда взято) ведётся локально у мейнтейнера (`docs/local/`, каталог в `.gitignore`) и в репозиторий
не попадает. Изменения протокола — отдельные решения, а не часть выноса.

Код и документация распространяются под MIT (см. [LICENSE](../LICENSE)): правообладатель у
перенесённых документов тот же, поэтому отдельной лицензии на них не требуется.
